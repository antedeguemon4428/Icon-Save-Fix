\# Icon Save Fix



Save complete icon kits and switch between them instantly from the Icon Kit!



\## Features



\- Save multiple named icon kits

\- Saves all icon types

\- Saves primary and secondary colors

\- Saves glow and glow color

\- Supports texture pack icons

\- Supports More Icons

\- Instantly switch between saved kits

\- Preview your saved icons before applying them

\- Delete kits you no longer want



Your saved kits persist between game sessions.



\## More Icons



Icon Save Fix integrates with More Icons to save and restore custom icons and traditional texture pack icons.
